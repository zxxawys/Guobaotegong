# 手机换新攻略（v4.2）

本地小应用，无需安装任何第三方库（Python 3.8+ 自带）。

## v4.2 主要变化

- 旧机维修库由 57 款扩充到 **258 款**（新增 201 款 2023–2024 年在售机型）。
- 维修价覆盖 **198 款**；其中 98 款为第三方报价，57 款为官方备件参考价，26 款含人工官方价，11 款混合口径，6 款演示数据；其余 60 款暂无报价，前台显示「数据不足」。
- 判定新增「年成本」对比：维修费 ÷ 剩余寿命 vs 新机官方价 ÷ 5 年，避免只看维修费绝对值。
- 首页品牌卡只展示 10 个品牌，iQOO 数据保留但不再单独出卡。

## 运行
```
python app.py
```
浏览器打开： http://127.0.0.1:8000

## 流程
1. 逐级点选旧手机：品牌 → 系列 → 具体机型（不需要手动输入；未被收录的机型不会出现在列表中）
2. 输入「您已使用__年」
3. 多选题（可勾选多项）：A 续航 / B 卡顿 / C 屏幕 / D 听筒 / E 扬声器 / F 充电口 / G 摄像头 / H 其他
4. 输出「维修价格：」+「维修后预计还可使用_年」
5. 结果页底部有「🔄 我想换新」按钮 → 进入换新推荐（见下）

- 维修后剩余年数 =（基准总寿命 - 已使用年数）× 折损系数
- 折损系数：A/D/E/F = 1.0；B/C = 0.2；G = 0.5（多选时取最低值）
- H 不输出维修价格，直接显示「建议换新」

## 我想换新（换新推荐）

维修结论页（含 H 分文）底部点「🔄 我想换新 →」即可进入；首页也有「已经决定换新？直接挑新机 →」入口。地址 `/new`。

三个筛选条件：

| 条件 | 选项 |
|---|---|
| ① 预算价格 | 1500 以下 / 1500–2500 / 2500–3500 / 3500–5000 / 5000–8000 / 8000 以上 |
| ② 品牌 | 不限（全部 437 款）/ 华为 / vivo / 荣耀 / OPPO / 小米 / 一加 / 三星 / 苹果 / realme / 魅族 |
| ③ 是否快充 | 不限 / 支持快充（≥33W）/ 不需要快充（<33W）/ 100W 以上超级快充 |

提交后从库内筛选，**横排列出 3 款推荐手机**（第 1 名居中带 👑 皇冠），每款给出「推荐理由」清单。

### ④ 使用偏好（v4.1 起支持多选）

| 偏好 | 加权维度 |
|---|---|
| 均衡 | 不偏科（默认） |
| 性能 | 芯片 / 内存 |
| 摄影 | 后置影像 |
| 续航 | 电池容量 + 官方续航 |
| 快充 | 有线充电功率 |
| 性价比 | 价格贴合度 |

可勾选多个偏好，命中的评分维度取**并集**统一 ×2.2 加权。

### 推荐卡片交互（v4.0 / v4.1）

- **点击卡片** → 新标签页打开该机型的 **ZOL 参数详情页**（`zol_url` 字段）
- **📊 对比按钮**（从维修报告跳过来时出现）→ 进入「维修 vs 换新」对比页

### 维修 vs 换新对比页（v4.0）

从维修报告点「🔄 对比换新机」→ 筛选出推荐 → 任选一款点「📊 拿这款和我的旧机对比」，生成对比表：

| 对比项 | 说明 |
|---|---|
| 芯片 / 屏幕 / 电池 / 后摄 / 充电 | 旧机参数 vs 新机参数 |
| 一次性花费 | 维修总价 vs 新机到手价 |
| 预计还能用 | 维修后剩余年数 vs 新机约 5 年 |
| 比维修多用 | 新机比维修后多使用几年 |
| 折合每年成本 | 一次性花费 ÷ 预计使用年数，自动得出「换新更划算 / 维修更划算」结论 |

打分维度（满分约 108）：充电 30 / 影像 25 / 电池 20 / 价格贴合 15 / 屏幕 8 / 存储 10 / 上市时间 8。若不限品牌，同一品牌最多占 2 席以保证多样性。

> 说明：不限价格时会以「主流换新预算段 2000–5000 元」为贴合基准，避免榜单被万元旗舰霸占。价格取 ZOL 电商报价，非实时。

- `market_phones` —— 在售机型库，437 条，供「我想换新」筛选使用

## 维修价口径（price_scope）

不同品牌、不同来源公开的维修价含义不一样，库内用 `price_scope` 标记（258 条）：

- **full（26 条）**：含人工的官方维修价。如 Apple 官方保外估价（含税含人工）、荣耀官网维修建议价、OPPO / 一加 / realme 官网备件价 + 50 元人工。
- **parts（57 条）**：官方配件 / 备件参考价，**不含人工**。新批次 31 款 OPPO / 一加 / realme 取自 OPPO 客服体系备件接口；华为 8 款、荣耀 5 款、vivo 3 款取自官网备件价；小米 3 款为官方保外物料价（媒体转引）。前台显示「官方配件价（不含人工）」。
- **mixed（11 条）**：同一机型同时存在含人工与不含人工的报价。如华为电池一口价（含人工）+ 其他部件官方备件价；小米电池 / 屏幕含 40 元人工 + 主板等仅配件价。具体项写在 `data_note`。
- **market（98 条）**：闪修侠、极客修等第三方平台明码标价，含人工，非官方。前台显示「第三方维修参考价（非官方）」。
- **demo（6 条）**：早期演示数据，未经官方核实，结论不作依据。
- **暂无报价（60 条）**：官方与第三方均未公开，该项不参与合计，不用估值填充。前台显示「数据不足，仅供参考」。其中 52 条标记 `spec`（仅有参数），8 条为早期行未写 scope。

补充口径：

- **华为**：电池为一口价（含人工）；其他部件为官方备件价（不含人工，人工费小件 80 / 主板 100 / 屏幕单体 160 元另计）。
- **三星**：中国官网备件价（资材费），保外维修另收 155 元人工；官方备件体系无听筒 / 扬声器单独条目。
- **折叠屏**：`screen_price` 统一取内屏组件价，外屏价写在备注。
- **主板**：统一取最低内存版本，具体版本写在备注。
- **旧机残值**：结果页按品牌保值率曲线估算（第 1–5 年），仅作参考，不是二手成交价；未接入回收平台行情。

前台结果页会在维修价格下显示「维修价口径：含人工官方维修价 / 官方配件价（不含人工）/ 混合口径 / 第三方维修参考价（非官方）」，明细见备注。

## 结论判定规则（结果页）

按顺序判定，命中即返回：

1. 剩余寿命 ≤ 0.05 年 → **建议更换**（寿命已尽）
2. 无任何维修报价 → **数据不足，仅供参考**
3. `price_scope = demo` → **数据不足，仅供参考**（演示价不作判定依据）
4. 维修费 ≥ 旧机估算残值 → **建议更换**（修理费超过旧机本身价值）
5. 维修费 ≥ 换新净成本（新机价 − 残值）→ **建议更换**（换新净支出更低）
6. 年成本对比：维修费 ÷ 剩余寿命 > 新机官方价 ÷ 5 年 → **建议更换**（把维修费摊到剩余寿命，比新机按 5 年分摊还贵）
7. 其余 → **建议维修**；若所选项中有故障无报价，结论会注明「实际成本可能被低估」

直接用 Navicat / DB Browser / sqlite3 往这张表里 INSERT 真实数据即可，程序不用改。
当前库内共 258 条：6 条演示数据（维修价为演示值）、98 条第三方报价、57 条官方备件参考价、26 条含人工官方价、11 条混合口径、60 条暂无报价。清理时请只处理确认的演示行，勿整表删除。

### market_phones（在售机型库 · 437 款）

数据来源：ZOL 中关村在线（2023 年及以后上市的 10 大品牌机型），采集于 2026-11。价格为电商报价，非实时。

| 字段 | 含义 |
|---|---|
| brand | 品牌 |
| model | 型号全名 |
| release_ym / release_year | 上市年月 / 年份 |
| price_min | 最低电商报价（元） |
| weight_g | 机身重量（g） |
| battery_mah | 电池容量（mAh） |
| charge_wired_w / charge_wireless_w | 有线 / 无线充电功率（W） |
| screen_inch / resolution | 屏幕尺寸（英寸）/ 分辨率 |
| rear_cam_mp / rear_cam_count / rear_cam_detail | 后置主摄像素 / 后摄数量 / 后摄完整描述 |
| front_cam_mp | 前置像素 |
| chipset | 处理器 |
| ram_gb / rom_gb | 运行内存 / 存储 |
| endurance_h / endurance_note | 官方续航时长（h）/ 续航说明 |
| colors / os | 配色 / 操作系统 |
| product_id / zol_url | ZOL 商品 ID / 参数页链接 |

字段填充率：价格 98.9%、重量 99.1%、电池 96.6%、有线充电 92.9%、屏幕 100%、摄影 99.3%、芯片 90.8%、上市日期 100%。

> 苹果官方不公布电池容量，故 Apple 机型 `battery_mah` 为 `NULL`，另有 `endurance_h` 记录官方续航时长。
> 索引：`price_min` / `brand` / `charge_wired_w` / `release_year` 四列已建索引，筛选为毫秒级。

### 数据维护

```sql
-- 换新推荐实际执行的查询（示例：3000 元档 + 快充）
SELECT * FROM market_phones
WHERE price_min >= 2500 AND price_min < 3500
  AND charge_wired_w >= 33
ORDER BY charge_wired_w DESC;

-- 各品牌均价
SELECT brand, COUNT(*) n, ROUND(AVG(price_min)) avg_price
FROM market_phones GROUP BY brand ORDER BY n DESC;
```

把新机型 `INSERT INTO market_phones (...)` 即可，前端无需改动。两表完全独立，增删市场数据不会影响维修价格库。
