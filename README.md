# 手机换新攻略

本地小应用，无需安装任何第三方库（Python 3.8+ 自带）。

## 运行
```
python app.py
```
浏览器打开： http://127.0.0.1:8000

## 流程
1. 逐级点选旧手机：品牌 → 系列 → 具体机型（不需要手动输入；未被收录的机型不会出现在列表中）
2. 输入「您已使用__年」
3. 多选题（可勾选多项）：A 续航 / B 卡顿 / C 屏幕 / D 听筒 / E 扬声器 / F 充电口 / G 摄像头 / H 其他
4. 输出「维修价格：」+「维修后预计还可使用_年」

- 维修后剩余年数 =（基准总寿命 - 已使用年数）× 折损系数
- 折损系数：A/D/E/F = 1；B/C = 0.5；G = 0.2
- H 不输出维修价格，直接显示「建议换新」

## 数据库说明（你之后自己写数据时看这里）
首次运行会自动生成 `phones.db`（SQLite），表结构如下：

| 字段 | 含义 | 对应选项 |
|---|---|---|
| brand | 品牌（如 苹果） | — |
| series | 系列（如 iPhone、Mate、数字系列；用于分组） | — |
| model | 型号（如 iPhone 15 Pro） | — |
| base_life_years | 基准总寿命（年） | 公式里的「基准总寿命」 |
| battery_price | 电池换新价 | A |
| motherboard_price | 主板换新价 | B |
| screen_price | 屏幕换新价 | C |
| earpiece_price | 听筒换新价 | D |
| speaker_price | 扬声器换新价 | E |
| charging_port_price | 充电口换新价 | F |
| camera_price | 摄像头换新价 | G |
| release_year | 上市年份（如 2026） | — |
| storage | 官方参考版本，统一写成 `12GB+256GB` | — |
| official_price_cny | 中国大陆官方参考价（人民币元） | — |
| soc | 处理器/芯片 | — |
| screen | 屏幕规格 | — |
| camera | 后置影像规格 | — |
| battery_mah | 电池容量（mAh） | — |
| source_url | 参数与价格来源链接 | — |
| data_note | 价格口径、调价、存疑等备注 | — |

> 上表 `release_year` 起的 10 个字段为可空扩展列：机型卡片显示年份、版本、官方价；结果页显示参数、官方参考价、来源、备注与维修价口径；后台列表增加年份/版本/官方价三列。后台添加表单暂不支持填写这些字段，缺省为 `NULL`。

## 维修价口径（price_scope）

不同品牌公开的维修价含义不一样，库内用 `price_scope` 标记：

- **小米**：官网给的是配件价，保外维修另收 1 级人工 40 元；标记 `parts` 的机型表示库内数字未含人工。
- **荣耀**：官网维修建议价已含人工，标记 `full`。
- **华为**：电池为一口价（Pura 99 元、Mate/nova 299 元，含人工）；其他部件为官方备件价（不含人工，人工费小件 80 / 主板 100 / 屏幕单体 160 元另计）。两者同时存在时标记 `mixed`。
- **第三方价（market）**：闪修侠、极客修等平台的明码标价，含人工，非官方。仅用于官方未公布的项目（目前只有 iPhone 16/17 的主板、听筒、扬声器、尾插）；与官方价同时存在时标记 `mixed`。
- **苹果**：Apple 官方保外估价，含税含人工，标记 `full`。
- **OPPO / 一加**：官网备件价 + 50 元人工，标记 `full`；vivo / iQOO 为官方配件价 + 50 元人工。
- **realme**：GT8 / GT8 Pro 经 OPPO 官方备件接口查询，为备件价 + 人工（电池一口价免人工），标记 `full`；GT7 Pro 为官网保外指导价，仅配件，标记 `parts`。
- **三星**：中国官网备件价（资材费），保外维修另收 155 元人工，标记 `parts`；官方备件体系无听筒/扬声器单独条目，折叠屏 `screen_price` 为内屏组件价。
- **空值**：官方未公开该机型或该部件价格。前台显示“暂无官方报价”，该项不参与合计，不用估值填充。
- **旧机残值**：结果页按品牌保值率曲线估算（第 1–5 年），仅作参考，不是二手成交价；未接入回收平台行情。

前台结果页会在维修价格下显示“价格口径：含人工官方维修价 / 官方配件价（不含人工）/ 混合口径（…详见备注）”；`mixed` 机型的具体项写在 `data_note`。

## 结论判定规则（结果页）

按顺序判定，命中即返回：

1. 剩余寿命 ≤ 0 → **建议更换**（寿命已尽）
2. 无任何维修报价 → **数据不足，仅供参考**
3. `price_scope = demo` → **数据不足，仅供参考**（演示价不作判定依据）
4. 维修费 ≥ 旧机估算残值 → **建议更换**（修理费超过旧机本身价值）
5. 维修费 ≥ 换新净成本（新机价 − 残值）→ **建议更换**（换新净支出更低）
6. 其余 → **建议维修**；若所选项中有故障无报价，结论会注明“实际成本可能被低估”

直接用 Navicat / DB Browser / sqlite3 往这张表里 INSERT 真实数据即可，程序不用改。
