手机参数数据库 使用说明
================================================
数据源：中关村在线 ZOL 参数页 + 品牌/年份列表页报价
采集时间：2026-11-03
覆盖范围：2023 年及以后上市的主流品牌机型
机型数量：437 款唯一型号（已按品牌+型号去重，同型号取最低价）

------------------------------------------------
一、文件说明
------------------------------------------------

1) 手机数据库.db     —— SQLite 数据库
   表：phones（437 行，25 个字段）
   视图：v_brand_summary（品牌汇总，直接查这个最方便）

   常用查询示例（用 DB Browser for SQLite 或 Python）：

   -- 各品牌汇总
   SELECT * FROM v_brand_summary;

   -- 3000 元以内、重量小于 190g 的轻便机型
   SELECT brand, model, price_min, weight_g, battery_mah
   FROM phones
   WHERE price_min <= 3000 AND weight_g < 190
   ORDER BY price_min;

   -- 续航最强：电池大 + 充电快
   SELECT brand, model, battery_mah, charge_wired_w, price_min
   FROM phones
   WHERE battery_mah >= 6000
   ORDER BY battery_mah DESC, charge_wired_w DESC;

   -- 摄影：主摄 5000 万以上 + 多摄
   SELECT brand, model, rear_cam_mp, rear_cam_count, rear_cam_detail, price_min
   FROM phones
   WHERE rear_cam_mp >= 50
   ORDER BY rear_cam_mp DESC, price_min;

   -- 某个品牌全机型
   SELECT * FROM phones WHERE brand = '小米' ORDER BY price_min DESC;

2) 手机参数对比.xlsx  —— Excel 表格，12 个工作表
   品牌汇总   ：10 个品牌的机型数、价格区间、均价、平均重量/电池/充电/屏幕
   全部机型   ：437 款，可按任意列筛选排序（已开启自动筛选、冻结首行）
   华为 / vivo / 荣耀 / OPPO / 小米 / 一加 / 三星 / 苹果 / realme / 魅族
              ：每个品牌单独一张表

------------------------------------------------
四、必须知道的数据局限
------------------------------------------------

1) 苹果电池容量是 0 —— 这是正常的
   苹果官方从不公布 mAh 容量，只给续航小时数。
   所以苹果机型的「电池(mAh)」为空，请看「官方续航(h)」列。
   其他品牌（华为/小米/OPPO/vivo 等）都正常有 mAh。

2) 价格会变
   价格是 ZOL 列表页的参考报价，不是京东/淘宝的实时价。
   促销、地区、渠道都会导致差异。用前建议核对。

3) 少数机型字段缺失
   约 1% 的机型 ZOL 页面本身没写全（如 iPhone 18 Pro Max 没有像素字段）。
   这是源站缺数据，不是采集错误。可点 ZOL链接 复核。

4) 覆盖 2023 年及以后上市机型
   更早的老机型（如 iPhone 8、iPhone 7）已被过滤掉，因为它们已不在售。
   如需老机型，可扩大年份范围重新采集。

5) 「最低价」口径
   同一型号有多个存储版本（128G/256G/512G）时，取其中最低的那个价格。
